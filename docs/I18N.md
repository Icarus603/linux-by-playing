# 多語系（i18n）

支援繁體中文（原文）、简体中文（自動轉換）、English（字典）。語言存在 `~/.linux-by-playing/lang`，第一次啟動會先選；`/language` 隨時切換。環境變數 `LBP_LANG=zh-TW|zh-CN|en` 可覆蓋（`LBP_LANG=en playnux verify` 用來驗證英文版的關卡）。

## 寫程式時

- `t('固定字串')`、``t`含 ${變數} 的字串```：依目前語言轉換。字典的 key 是繁體原文，樣板的變數用 `{}` 代表（依序填入，也可寫 `{0}` `{1}` 重排）。
- 模組層級的資料表（徽章、等級、小技巧…）用 `T('…')` 標記，**使用時**再 `tr(…)`，否則語言切換不會生效。
- 簡體不需要字典：`src/i18n/index.ts` 用 OpenCC（`twp` → `cn`）加少量補丁轉換。
- 英文字典：`src/i18n/en.json`（介面與 Pip 台詞）、`src/i18n/feedback.en.json`（關卡判定腳本印出的回饋，key 內 `{}` 代表任意片段）、`src/i18n/levels.en.json`（每一關的 title / story / goal / hints / reveal，以及 `stage:N`）。

## 新增或修改文字之後

```bash
bun scripts/i18n-extract.ts          # 列出還沒有英文的 t()/T() 字串
bun scripts/i18n-levels.ts fields    # 列出還沒有英文的關卡文字
bun scripts/i18n-levels.ts feedback  # 列出還沒有英文的判定回饋
bun test src/i18n                    # 缺漏或變數數量對不上會失敗
```

## 關卡裡的資料檔

setup 會寫進容器的檔案內容若是中文（例如 `1-04` 的日誌），要依 `$LBP_LANG` 分支寫出英文版（見 `levels/01-survival/04-cat.yaml`）；判定腳本請用兩種語言都能通過的寫法。
